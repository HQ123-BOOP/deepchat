# chat-demo

English | [简体中文](README.zh-CN.md)

An LLM chat client that supports different vendors and protocols. Deeply modified from deepseek-ai's chat-demo.

The project is still in the early stages of development, so there might be some rough edges.

Feel free to submit issues.
